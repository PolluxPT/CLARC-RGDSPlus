# Changelog

## v1.0.0 — 7 November 2026

- Initial public standalone release for RGDS+ stock Linux.
- Preserves the owner-confirmed working Alpha 1.4 gameplay and graphics runtime.
- Uses the original Chasm physical calibration for face, shoulder and START/SELECT buttons.
- D-pad and left stick share the same movement path.
- L1/R1 emulate right-stick left/right for robot rotation.
- Correct START/SELECT pause and hold-to-exit handling; no shoulder/start button exchange.
- Physical volume curve, volume restoration, bottom-screen shutdown and restoration.
- Local first-launch import of the owner's original Linux archive; no game-data distribution.
